  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.325\textwidth}
      \begin{block}{Technika}
        \footnotesize
        Python (biblioteka standardowa), SQLite, Leaflet: zero zależności. Obraz Docker 47~MB; Ansible + Caddy
        (automatyczny HTTPS) na dowolny VPS; 503 testy bez sieci. Usługi opcjonalne mają działanie zastępcze.
      \end{block}
    \end{column}
    \begin{column}{0.325\textwidth}
      \begin{block}{Bezpieczeństwo i~prywatność}
        \footnotesize
        Bez konta anonimowo, bez zapisu IP. Profil to preferencje, nigdy diagnoza. Logowanie kodem z~e-maila,
        skróty SHA-256, ciasteczko HttpOnly / Secure, limity rozmiaru, polityka prywatności w~aplikacji, dane w~UE.
      \end{block}
    \end{column}
    \begin{column}{0.325\textwidth}
      \begin{block}{Dostępność cyfrowa jako przewaga}
        \footnotesize
        Główny scenariusz sprawdzony pod WCAG~2.2 A/AA: klawiatura, czytnik ekranu, kontrast, mapa jako tekst.
        Do zrobienia: audyt z~użytkownikami, znaczniki mapy z~klawiatury, panele. Warunek sprzedaży instytucjom.
      \end{block}
    \end{column}
  \end{columns}
  \vspace{0.5mm}
  \muted{Utrzymanie poza UMK: operator (spółka lub fundacja), infrastruktura ok.~60--120~zł/mies., aktualizacja jednym poleceniem,
    dane miasta odświeżają się same, moderacja w~panelu administratora.}

  \note[item]{Najważniejsze zdanie: pozyskiwanie danych jest oddzielone od prezentacji. Import, snapshoty i~pamięć podręczna to osobny krok; aplikacja czyta tylko z~bazy przez API, więc źródło albo frontend można podmienić bez ruszania reszty.}
  \note[item]{Usługi opcjonalne: Claude API (rekomendacje; bez klucza reguły słów kluczowych), OpenRouteService (trasy dla wózka), Nominatim (wyszukiwanie z~przeglądarki), backend Rampa (FastAPI, PostgreSQL, model obserwacja $\rightarrow$ głos $\rightarrow$ zaufanie) przez adapter w~\texttt{api.js} -- ścieżka skalowania na duże wdrożenie.}
  \note[item]{Pytanie „jakie dane zbieracie?”: bez konta żadnych; z~kontem e-mail, opcjonalna nazwa, profil potrzeb. Tabela w~polityce prywatności w~aplikacji. Wyzwanie wprost prosi, by nie wymagać informacji o~niepełnosprawności. Limity: 10~kB na żądanie, zdjęcia 4~MB; treści użytkowników escapowane (testy).}
  \note[item]{WCAG: nie mówić „jesteśmy zgodni”, mówić „sprawdzone kryteria A/AA w~głównym scenariuszu, lista braków jest jawna”: fokus przy odświeżaniu list, krótkie komunikaty live, waga kształtem i~podpisem, 400\,\% powiększenia, cele 44~px. Zmiany objęte testami \texttt{AccessibilityTests}.}
