  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.325\textwidth}
      \begin{block}{Technology}
        \footnotesize
        Python (standard library), SQLite, Leaflet: zero dependencies. 47~MB Docker image; Ansible + Caddy
        (automatic HTTPS) on any VPS; 503 tests, no network. Optional services have fallbacks.
      \end{block}
    \end{column}
    \begin{column}{0.325\textwidth}
      \begin{block}{Security and privacy}
        \footnotesize
        Anonymous without an account, no IP logging. The profile is preferences, never a diagnosis. Sign-in by e-mail code,
        SHA-256 hashes, HttpOnly / Secure cookie, size limits, privacy policy in the app, data in the EU.
      \end{block}
    \end{column}
    \begin{column}{0.325\textwidth}
      \begin{block}{Digital accessibility as an advantage}
        \footnotesize
        The main scenario checked against WCAG~2.2 A/AA: keyboard, screen reader, contrast, map as text.
        Still to do: an audit with users, keyboard access to map markers, panels. A precondition for selling to institutions.
      \end{block}
    \end{column}
  \end{columns}
  \vspace{0.5mm}
  \muted{Operations outside the City: an operator (company or foundation), infrastructure about PLN~60--120 (EUR~15--30) a month,
    one-command updates, city data refreshes itself, moderation in the admin panel.}

  \note[item]{Key sentence: data acquisition is separated from presentation. Import, snapshots and cache are a separate step; the app reads only from the database through the API, so a source or the frontend can be swapped without touching the rest.}
  \note[item]{Optional services: Claude API (recommendations; keyword rules without a key), OpenRouteService (wheelchair routes), Nominatim (search from the browser), the Rampa backend (FastAPI, PostgreSQL, observation $\rightarrow$ vote $\rightarrow$ trust model) through the \texttt{api.js} adapter: the scaling path for a large deployment.}
  \note[item]{Question “what data do you collect?”: without an account, none; with an account, e-mail, an optional display name and the needs profile. The table is in the privacy policy inside the app. The brief explicitly asks not to require disability information. Limits: 10~kB per request, photos 4~MB; user content escaped (tested).}
  \note[item]{WCAG: do not say “we are compliant”; say “A/AA criteria checked on the main scenario, the list of gaps is open”: focus kept across list refreshes, short live announcements, severity by shape and label, 400\,\% zoom, 44~px targets. Covered by the \texttt{AccessibilityTests} suite.}
